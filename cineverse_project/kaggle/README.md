# Optional Kaggle workflow for CineVerse

1. Open https://www.kaggle.com/datasets
2. Search for a movie ratings or movie metadata dataset whose license permits your intended use.
3. Create a Kaggle Notebook and attach the dataset.
4. Explore columns, missing values, genres, languages, and rating distributions.
5. Prototype a recommendation model in the notebook.
6. Export only your own code/model artifacts if the dataset license permits redistribution.
7. Keep the Streamlit app in GitHub; Kaggle is for data exploration and experiments, not the public website host.

Do not upload API tokens or private credentials into a public notebook.
